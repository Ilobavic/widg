## Design Context

### Users
* **Who they are**: Developers, engineering managers, DevOps engineers, and tech workers.
* **Context**: Used during their morning routine (often on mobile or desktop) to quickly digest high-priority updates before starting work.
* **Job to be done**: Filter out the noise from Slack, Jira, and email to identify exactly what requires immediate action today.

### Brand Personality
* **Personality**: Focused, Calm, Signal-focused.
* **Voice**: Concise, editorial, and neutral.
* **Emotional Goals**: Reduce morning stress, establish clarity, and build confidence in priorities.

### Aesthetic Direction
* **Theme**: Deep dark glassmorphism.
* **Visual Tone**: Modern, tech-focused, and premium.
* **Layout**: Minimal, centered column, cards-based list with smooth animations.
* **Color Palette**: Dark base (`#090b18`) with translucent backdrops, subtle glow effects, and functional semantic colors (Red for high, Orange for medium, Green for low).
* **Corners**: Smoothly rounded with `16px` (`var(--radius-md)`) to `24px` (`var(--radius-lg)`).

### Implementation Defaults
* **Framework**: React 19 + TypeScript (Vite 8)
* **Styling**: Vanilla CSS (CSS variables, reset, styling in [src/index.css](file:///c:/Users/lucky/Desktop/Codex%20project/src/index.css))
* **Backend**: Node.js/TypeScript serverless functions in [api/brief.ts](file:///c:/Users/lucky/Desktop/Codex%20project/api/brief.ts)
* **Form & Logic**: Inline React states with native form inputs

### Design Principles
1. **Prioritize Spacing Over Lines**: Create structural separation using spacing tokens and grid alignment before drawing borders.
2. **Color is Information, Not Paint**: Restrict vibrant colors to critical semantic badges (urgency indicators). The rest of the interface should remain muted and neutral.
3. **Glassmorphic Depth & Elevation**: Maintain a consistent layered hierarchy where cards hover above background drift orbs using backdrops, subtle borders, and soft shadows.
